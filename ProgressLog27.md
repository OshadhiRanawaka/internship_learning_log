## Daily Progress Log

**Thursday - 5.11.2026**
- Went through the **Object-Oriented Programming** lessons:
  - OOP organises code around **objects** that contain both data and the functions to manipulate that data
  - An object is an instance of a **class**, which bundles data and functionality together, making code more organised and reusable
  - **Methods** are functions associated with a class, accessed with dot notation
  - **Attributes** are values associated with an object or class, accessed by name with dot notation but without parentheses
  - Python has **core classes** like integers, floats, strings, lists, and dictionaries, each with built-in methods and attributes
- Studied **Variables and Data Types**:
  - Variables act like **labelled containers** that point to values stored in memory
  - They can hold strings, integers, floats, lists, and dictionaries, and Python **determines the type dynamically** on assignment
  - Assignments store values, expressions combine numbers, symbols, or variables to produce results, and variables can be **reassigned**
  - The order of code execution affects variable values, especially in Jupyter Notebooks
  - Variables make it easy to find maximum or minimum values in a list and to run calculations by name instead of raw values

**Friday - 6.11.2026**
- Completed **Creating Precise Variable Names**:
  - Keywords such as `for`, `in`, `if`, and `else` are **reserved** and cannot be used as variable names
  - Names must start with a **letter or underscore** and can include letters, numbers, and underscores, but no spaces, special characters, or parentheses
  - Using names of existing functions like `print` or `str` causes errors
  - Coding environments highlight keywords in a special colour to help avoid mistakes
  - **Parentheses** follow standard order of operations, so expressions inside them are evaluated first
- Completed **Data Types and Conversions**:
  - **Strings** are sequences of characters in quotes and are **immutable**
  - **Integers** are whole numbers and **floats** are decimal numbers
  - Mixing types, such as adding an integer to a string, raises a **TypeError**
  - `type()` identifies the data type of a value or variable
  - Conversion can be **implicit** (integers to floats in arithmetic) or **explicit** using `int()`, `float()`, and `str()`
  - Reading error messages and searching online or asking the data community are key debugging habits
